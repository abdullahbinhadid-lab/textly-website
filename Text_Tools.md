## Technical Stack
- **Framework:** Astro, Tailwind CSS, TypeScript
- **Hosting:** Cloudflare Pages
- **Processing:** 100% client-side JavaScript for basic text tools
- **Text to Speech:** Web Speech API (browser native)
- **Speech to Text:** Web Speech Recognition API
- **AI features:** OpenAI GPT-4o-mini / Claude Haiku API

## Differentiation
1. All basic tools run client-side (privacy-first)
2. No signup required for any free tool
3. All-in-one suite (competitors offer one tool per site)
4. Real-time analysis (word count updates as you type)
5. Modern, clean UI with dark mode
6. SEO-specific features (keyword density, reading time, slug generator)
